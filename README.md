## Dokumentasi REST Endpoint & Struktur JSON (Tahap 1)
- **Endpoint yang digunakan:** `https://course-api-pearl.vercel.app/courses`
- **HTTP Method:** `GET`
- **Status Code:** `200 OK`
- **Resource:** `courses`
- **Empat Field JSON Utama:** `id`, `code`, `title`, `credits`, `status`

Contoh JSON:
```json
{
  "id": 1,
  "code": "MOB01",
  "title": "Git & GitHub",
  "credits": 2,
  "status": "active"
}
